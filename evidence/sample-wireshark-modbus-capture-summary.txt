ANALYST NOTE

The absence of any authentication challenge across all four captured Modbus/OPC-UA
sessions confirms VUL-005 (legacy protocol without authentication) is not a
theoretical/architectural concern but an observed, exploitable condition in this
lab environment: any host with network reachability to port 502 or 4840 on these
assets can issue read AND write commands without credentials. This directly
supports the RISK-001 and RISK-005 severity ratings in the formal risk assessment
report, since network reachability alone -- not credential compromise -- is
sufficient to manipulate PLC register values in this environment.
